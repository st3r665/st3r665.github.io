介绍什么是格式化字符串函数

众所周知，在初学c语言的时候，有一个不是太离谱的函数叫做printf()，主要就是用来格式化输出一些string，并且可以传一些变量作为参数，动态的输出这些string并且保持格式不变，所以这个函数也叫格式化字符串函数。同时，在c语言中有许多这样类似的格式化字符串函数。众所也周知，c语言是一个漏洞很多的语言，有无限制读入的gets函数，所以，格式化函数当然也有漏洞，今天就来讲讲格式化字符串漏洞。
